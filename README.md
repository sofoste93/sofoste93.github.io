# Sofostech portfolio

Personal portfolio and collection of web experiments by Stéphane Sob.

## Live websites

- [sofoste.de](https://sofoste.de) — current official website
- [sofoste93.github.io](https://sofoste93.github.io/) — GitHub Pages demo and project archive
- [StimmeAfrikas](https://stimmeafrikas.com) — completed choir website
- [YouTube @sofoste](https://www.youtube.com/@sofoste) — music and video channel

The former domains `sofoste.tech` and `sofoste.com` are retired and should no longer be used.

## Run locally

From the project directory:

```powershell
php -S 127.0.0.1:4173
```

Then open [http://127.0.0.1:4173/](http://127.0.0.1:4173/).
