# Sofoste Orbital Lab V3

An interactive solar-system simulation built for the Sofostech portfolio with HTML Canvas, CSS and vanilla JavaScript.

## V3 features

- Animated heliocentric view with compressed orbital distances and relative orbital periods
- Nine selectable bodies: eight planets plus Pluto
- Live planet telemetry and image inspector
- Simulation speed, zoom, orbit, label and grid controls
- Canvas selection, search, fullscreen and keyboard pause control
- Responsive mission-control interface for desktop and mobile
- No framework or build step required

## Controls

- Select a planet from the navigation panel or directly on the orbital map.
- Use **Simulation speed** for time warp and **Viewport zoom** to change the map scale.
- Press the space bar to pause or resume the simulation.

## Run locally

```powershell
php -S 127.0.0.1:4173
```

Open [http://127.0.0.1:4173/my_solar_system/](http://127.0.0.1:4173/my_solar_system/).
