# Sofoste Color Lab V3

A compact color design instrument built with HTML, CSS and vanilla JavaScript.

## Live demo

**[Open Color Lab V3](https://sofoste93.github.io/color_picker/)**

## Features

- Live HEX, RGB and HSL conversion
- Analogous, complementary, triadic and monochrome palette generation
- WCAG contrast ratio with AA and AAA indicators
- Click-to-copy values and CSS variable export
- Persistent recent-color history using local storage
- Responsive interface with no framework or build step

## Run locally

```powershell
php -S 127.0.0.1:4173
```

Open [http://127.0.0.1:4173/](http://127.0.0.1:4173/).
